# Tree Lab — BST & AVL

เว็บไซต์เรียนรู้โครงสร้างข้อมูล สร้าง BST และ AVL ด้วย Java OOP แสดงขั้นตอนเพิ่ม ค้นหา ลบ หมุน ปุ่มเปรียบเทียบ และบันทึกประวัติใน SQLite

## เริ่มใช้งาน

ต้องมี Java 17 ขึ้นไป และ Maven 3.6.3 ขึ้นไป เชื่อมต่ออินเทอร์เน็ตครั้งแรกเพื่อดาวน์โหลด dependencies

```bash
mvn spring-boot:run
```

เปิด http://localhost:8080 และหยุดด้วย Ctrl+C ฐานข้อมูล `tree-lab.db` สร้างในโฟลเดอร์ที่สั่งรัน

## การใช้งาน

เลือก BST หรือ AVL → ใส่จำนวนเต็มคั่นด้วยจุลภาค → สร้างต้นไม้ → เลือกดูทีละขั้นหรือทั้งหมด แล้วเพิ่ม ลบ ค้นหาได้ สลับชนิดต้นไม้เพื่อจำลองลำดับเดิม ปุ่มเปรียบเทียบเล่นคำสั่งเดียวกันทั้งสองต้น ปุ่มบันทึกเก็บประวัติลง SQLite และเปิดกลับมาได้

- ค่าซ้ำไม่ถูกเพิ่ม และลบค่าที่ไม่มีจะไม่เปลี่ยนต้นไม้
- กรณีลบโหนดที่มีลูกสองด้าน ใช้ค่าต่ำสุดของต้นไม้ย่อยด้านขวาแทน (inorder successor)
- AVL balance factor = ความสูงซ้าย − ความสูงขวา ความสูงต้นไม้เปล่า = 0 โหนดเดี่ยว = 1; กรณี LR และ RL แสดงการหมุนทีละครั้ง
- ลำดับ traversal แสดงผลของต้นไม้สุดท้าย แม้กำลังดูภาพขั้นตอนก่อนหน้า
- รองรับคำสั่งไม่เกิน 200 รายการ และจำนวนเต็ม 32 บิต แนะนำใช้จำนวนน้อยเพื่อให้อ่านภาพง่าย

## OOP และโครงสร้าง

`BinarySearchTree` มีโหนดและเมธอดเพิ่ม ลบ ค้นหา `AVLTree extends BinarySearchTree` และ override `afterChange()` เพื่อตรวจสมดุลและหมุนหลังเพิ่ม/ลบ เป็นตัวอย่าง inheritance และ polymorphism ข้อมูลในแต่ละขั้นถูกคัดลอกเป็น snapshot ส่วน `TreeController` ให้ API และเก็บประวัติ SQLite หน้าเว็บอยู่ใน `src/main/resources/static`

รันทดสอบด้วย `mvn test` ก่อนนำขึ้น GitHub สามารถสร้าง repository แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ ไฟล์ `.gitignore` ไม่รวมฐานข้อมูลและ build; ไม่ควรใส่ข้อมูลส่วนตัวลงในฐานข้อมูลที่จะเผยแพร่

GitHub เก็บ source code เท่านั้น หากต้องการใช้งานออนไลน์ ต้องมีโฮสติ้งที่รัน Java และพื้นที่จัดเก็บ SQLite แบบถาวร แอปมีระบบสมัครสมาชิกและเข้าสู่ระบบแล้ว ประวัติแยกตามเจ้าของ รายละเอียดการใช้งานและอัปเกรดอยู่ใน LOGIN_GUIDE.md


## ระบบสมาชิก

เพิ่ม Spring Security, BCrypt และเซสชันพร้อม CSRF ผู้เยี่ยมชมทดลองต้นไม้ได้ แต่การบันทึก เปิด และลบประวัติต้องเข้าสู่ระบบ โดยแต่ละบัญชีเข้าถึงได้เฉพาะประวัติของตัวเอง ดู LOGIN_GUIDE.md สำหรับวิธีรันและการย้ายฐานข้อมูลเดิม
